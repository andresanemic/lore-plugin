# Escritura — Community Manager

## Hilos

La apertura de un hilo va sin numerar. Las publicaciones siguientes cierran con numeración simple
`2/N`, `3/N`… en la última línea. No se agregan encabezados como “Post 2” o “Tweet 3”.

## Llamada a la acción

Cada pieza tiene una sola acción primaria. La CTA comienza con un verbo y comunica el beneficio
concreto. Se evitan cierres genéricos como “más información”, “contáctanos”, “síguenos” o “visita
nuestra web” cuando compiten con la acción principal.
