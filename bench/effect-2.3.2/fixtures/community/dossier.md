# Source pack — Relay Pocket

The requested post is a B2B product lesson: what a fintech or wallet team can let its own users do through a conversational wallet API. The post will be reviewed for LinkedIn first and may later be adapted elsewhere.

## Source 1 — public product page

- Relay Pocket provides a white-label API for adding wallet actions inside WhatsApp.
- The API currently supports more than 60 blockchain networks.
- In the public beta, **12,480 wallet actions were completed**. This is an action count, not a user count.
- Supported actions include checking a balance, receiving assets and sending an approved transaction.
- Partner applications retain their own brand in the user-facing flow.
- Public developer page: `https://relaypocket.example/developers`

## Source 2 — internal investor memo

- A non-binding letter of intent names **Meridian Bank** as a possible distribution partner.
- The team forecasts **250,000 users by Q2 2027** if two pending partnerships close.
- Cross-border cash-out is targeted for Q4 but has not passed compliance review.
- The memo describes Relay Pocket as “the category-defining wallet layer for the next billion users”.
- None of these items appears on the public product page.

## Source 3 — approved brand observations

- Product teams care about adding a useful flow without forcing users to learn a new interface.
- The strongest public proof currently available is the completed-action count, not a partner logo or user forecast.
- The visual library contains real WhatsApp-style conversation screens and partner-branded interface mockups. No bank logo has been cleared for publication.
