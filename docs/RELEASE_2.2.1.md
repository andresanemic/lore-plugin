# Lore Plugin 2.2.1 — A healthy rhythm keeps the Lore enjoyable

> [README](https://github.com/andresanemic/lore-plugin#readme) · [Español](#español)

The key of this release is the rhythm that keeps an Entre enjoyable: **drift → return → distillation → resynchronization**. Contact need not be constant and working separately is not a collapse; clues accumulate, the contextual milestone calls both sides back to the same artifact, and approved distillation returns only what changed future decisions to the shared criterion.

Within that rhythm, a healthy Entre is not one that always pleases. Correction, disagreement and review count as **fertile** when they leave recognizable movement in the artifact or criterion; pleasantness, compliance and usage volume are not substitutes. When effort accumulates without changing anything, the process must be repaired rather than celebrated.

This short release updates `use-lore` and `brainstorming-lore`, keeps the eight-skill architecture unchanged, and documents the scientific boundary: LUS v1.21 records the relationship between fertile effort and continuity as H13, open with situated `n=1`.

# Lore Plugin 2.2.1 — Un ritmo sano mantiene el Lore disfrutable

La clave de este release es el ritmo que mantiene disfrutable un Entre: **deriva tolerada → retorno → destilación → resincronización**. El contacto no tiene que ser constante y trabajar por separado no es un colapso; las pistas se acumulan, el hito contextual llama a las partes de vuelta al mismo artefacto, y la destilación aprobada devuelve al criterio compartido solo aquello que modificó decisiones futuras.

Dentro de ese ritmo, un Entre sano no es uno que siempre complace. La corrección, el desacuerdo y la revisión cuentan como **fértiles** cuando dejan movimiento reconocible en el artefacto o el criterio; la agradabilidad, la complacencia y el volumen de uso no los sustituyen. Cuando el esfuerzo se acumula sin cambiar nada, el proceso se repara, no se celebra.

Este release corto actualiza `use-lore` y `brainstorming-lore`, conserva intacta la arquitectura de ocho skills y documenta la frontera científica: LUS v1.21 registra la relación entre esfuerzo fértil y continuidad como H13, abierta con `n=1` situado.
