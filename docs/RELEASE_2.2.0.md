# Lore Plugin 2.2.0 — Complex work without losing the thread

> [README](https://github.com/andresanemic/lore-plugin#readme) · [Español](#español)

Lore can now guide a complex deliverable from its first decisions to reviewed delivery. One accumulated artifact keeps the original intention recognizable and correctable as the work grows.

This release adds:

- provisional canon and a reviewed first victory for bots born from a minimal idea;
- explicit structure, an approved quality yardstick, verified tools or connectors, reviewable batches and human review for complex deliverables;
- contextual capture: related clues can accumulate and return through one visible distillation proposal;
- autonomy with return: work does not require constant contact to stay synchronized;
- an optional professional profile that grows from reviewed, sourced clues during real work and can
  also emerge through ADD without a first-use biography interview;
- ADD as the entry from existing material, plus cleaner CRYSTALLIZE memory cards grouped by owner
  without changing their extraction markers;
- OpenCode as a documented third installation route;
- Case 17, Permanent Artist, with its product-specific details kept outside generic skill law.

Lore coordinates document, scraping, browser, MCP and publishing tools; it does not replace them or authorize publication. No ninth skill was added. Start a new session after installing.

# Lore Plugin 2.2.0 — Trabajo complejo sin perder el hilo

Lore ahora puede conducir un entregable complejo desde sus primeras decisiones hasta la entrega revisada. Un artefacto acumulado mantiene reconocible y corregible la intención original mientras el trabajo crece.

Esta versión añade:

- canon provisional y una primera victoria revisada para bots nacidos desde una idea mínima;
- estructura explícita, vara de calidad aprobada, herramientas o conectores verificados, lotes revisables y revisión humana para entregables complejos;
- captura contextual: las pistas relacionadas pueden acumularse y volver mediante una sola propuesta visible de destilación;
- autonomía con retorno: el trabajo no exige contacto constante para mantenerse sincronizado;
- un perfil profesional opcional que crece desde pistas revisadas y con fuente durante el trabajo, y
  que ADD también puede descubrir sin convertir el estreno en una entrevista biográfica;
- ADD como entrada desde material existente, más memory cards de CRYSTALLIZE limpias y agrupadas
  por dueño sin cambiar sus marcadores de extracción;
- OpenCode como tercera ruta de instalación documentada;
- el Caso 17, Permanent Artist, con sus detalles de producto fuera de las leyes genéricas de las skills.

Lore coordina herramientas de documentos, scraping, navegador, MCP y publicación; no las reemplaza ni autoriza publicaciones. No se añadió una novena skill. Abre una sesión nueva después de instalar.
