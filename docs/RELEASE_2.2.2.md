# Lore Plugin 2.2.2 — Hygiene when importing external criterion

> [README](https://github.com/andresanemic/lore-plugin#readme) · [Español](#español)

The key of this release is hygiene when importing external criterion: invisible Unicode can survive human review while remaining executable for another model family. GLOSSOPETRAE measures the gap at `R=100% M=0%` on tag-char and PUA channels and confirms that half the frontier has zero blind spots and Anthropic has ten.

Within that measurement, the fix is not a language engine. Imported text that looks clean to one tokenizer can carry payload for another. This short release adds a deterministic sanitization step to `save-to-lore` in `GRAFT` mode before the threshold, keeps the eight-skill architecture unchanged, and documents the scientific boundary: LUS records the `GLOSSOPETRAE` engine as rejected for Lore Plugin — procedural xenolinguistics is not criterion — and retains only its lesson as a hygiene invariant.

# Lore Plugin 2.2.2 — Higiene al importar criterio externo

> [README](https://github.com/andresanemic/lore-plugin/blob/main/README.md#español)

La clave de este release es la higiene al importar criterio externo: Unicode invisible puede sobrevivir la revisión humana y seguir siendo ejecutable para otra familia de modelos. GLOSSOPETRAE mide la brecha en `R=100% M=0%` en canales tag-char y PUA y confirma que la mitad de la frontera tiene cero blind spots y Anthropic diez.

Dentro de esa medición, el arreglo no es un motor de lenguas. Texto importado que se ve limpio para un tokenizer puede portar payload para otro. Este release corto añade un paso determinístico de sanitización a `save-to-lore` en modo `GRAFT` antes del umbral, conserva intacta la arquitectura de ocho skills y documenta la frontera científica: LUS registra el engine `GLOSSOPETRAE` como rechazado para Lore Plugin — la xenolingüística procedural no es criterio — y conserva solo su lección como invariante de higiene.
