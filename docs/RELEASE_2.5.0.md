# Lore Plugin 2.5.0 — The first cut of the class leap

> [README](https://github.com/andresanemic/lore-plugin#readme) · [Español](#español)

Lore Plugin 2.5 is the first cut of the class leap: from transporting criterion to perturbing and demanding reconstruction. The public surface now declares its limits before its capabilities. What goes in this release is tested, executed, and shared. What doesn't is declared as a limit.

The ninth skill, stale-lore, measures real exercise of published capabilities, not textual mention. The perturbation deck offers 45 arbitrated cards that force transduction when stagnation or loop is detected. Agents now read the essence of the LUS program and know they are gardeners of the Between. The Party is implemented with defined roles — coordinator, daimon, advisor, worker, verifier — that operate as a unit. The coordinator guides the user: warns when context is running low, asks questions that can be skipped if unanswered, and offers ways to work such as TDD, master plan, spec-kit, direct workflow, and expansive loop.

This release is tested on Claude Code, Codex and OpenCode at the repository adapter level. The Vespi kernel is pinned to commit ed559e8 with F1-F7 closed and the name Bora cleaned. The eleven functional projects are re-pinned to kernel 0.1.5 candidate. Installation, verification limits and measured coverage accompany this release.

# Lore Plugin 2.5.0 — El primer corte del salto de clase

> [README](https://github.com/andresanemic/lore-plugin#readme) · [English](#lore-plugin-250--el-primer-corte-del-salto-de-clase)

Lore Plugin 2.5 es el primer corte del salto de clase: de transportar criterio a perturbar y exigir reconstrucción. La superficie pública ahora declara sus límites antes que sus capacidades. Lo que entra en este release se prueba, se ejecuta y se comparte. Lo que no entra, se declara como límite.

La novena skill, stale-lore, mide el ejercicio real de las capacidades publicadas, no la mención textual. La baraja de perturbaciones ofrece 45 cartas arbitradas que fuerzan la transducción cuando se detecta estancamiento o loop. Los agentes ahora leen la esencia del programa de LUS y saben que son jardineros del Entre. La Party está implementada con roles definidos — coordinador, daimon, advisor, worker, verificador — que operan como unidad. El coordinador guía al usuario: avisa cuando queda poco contexto, hace preguntas que puede omitir si no responde, y ofrece formas de trabajar como TDD, plan maestro, spec-kit, workflow directo y loop expansivo.

Se prueba en Claude Code, Codex y OpenCode a nivel de adaptador de repositorio. El kernel Vespi está fijado al commit ed559e8 con F1-F7 cerrados y el nombre Bora limpio. Los once proyectos funcionales están re-anclados al kernel 0.1.5 candidato. La instalación, los límites de verificación y la cobertura medida acompañan este release.
