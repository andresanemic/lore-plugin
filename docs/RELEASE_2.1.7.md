# Lore Plugin 2.1.7 — Complex work without losing the thread

> [README](https://github.com/andresanemic/lore-plugin#readme) · [Español](#español)

Lore can now guide a complex deliverable from its first structural decisions to reviewed delivery. The project keeps one accumulated artifact, so the person can still recognize the original intention and correct its direction while the work grows.

This release adds:

- provisional canon and a reviewed first victory for bots born from a minimal idea;
- explicit structure, an approved quality yardstick, verified tools or connectors, reviewable batches and human review for complex deliverables;
- contextual capture: related clues can accumulate and return through one visible distillation proposal;
- autonomy with return: work does not require constant contact to stay synchronized;
- ADD as the entry from existing folders, documents, chat summaries and notes, plus CRYSTALLIZE as
  a portable, extractable Markdown memory card across models;
- OpenCode as a documented third installation route;
- Case 17, Permanent Artist, with its product-specific details kept outside generic skill law.

Lore coordinates document, scraping, browser, MCP and publishing tools; it does not replace them or authorize external publication. No ninth skill was added.

After installing, start a new session.

# Lore Plugin 2.1.7 — Trabajo complejo sin perder el hilo

Lore ahora puede conducir un entregable complejo desde sus primeras decisiones estructurales hasta la entrega revisada. El proyecto mantiene un solo artefacto acumulado, para que la persona siga reconociendo su intención original y pueda corregir el rumbo mientras el trabajo crece.

Esta versión añade:

- canon provisional y una primera victoria revisada para bots nacidos desde una idea mínima;
- estructura explícita, vara de calidad aprobada, herramientas o conectores verificados, lotes revisables y revisión humana para entregables complejos;
- captura contextual: las pistas relacionadas pueden acumularse y volver mediante una sola propuesta visible de destilación;
- autonomía con retorno: el trabajo no exige contacto constante para mantenerse sincronizado;
- ADD como entrada desde carpetas, documentos, resúmenes de chats y notas, más CRYSTALLIZE como
  memory card Markdown portable y extraíble entre modelos;
- OpenCode como tercera ruta de instalación documentada;
- el Caso 17, Permanent Artist, con sus detalles de producto fuera de las leyes genéricas de las skills.

Lore coordina herramientas de documentos, scraping, navegador, MCP y publicación; no las reemplaza ni autoriza publicaciones externas. No se añadió una novena skill.

Después de instalar, abre una sesión nueva.
